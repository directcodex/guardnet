# GuardNet

AI-powered cybersecurity and digital threat intelligence platform.

## Features

- AI phishing detection
- Scam and fraud analysis
- Suspicious link scanner
- QR code safety checker
- Privacy risk monitoring
- Fake profile detection
- Threat alerts dashboard
- Real-time security insights

## Tech Stack

- Next.js
- Tailwind CSS
- Vercel
- TypeScript
- OpenAI API
- Supabase

## Vision

GuardNet helps everyday users, creators, families, and businesses stay protected online using modern AI-powered security tools.
